## 你要动手的 Git 五步（约 40 分钟）

1. B 站「Git 入门 尚硅谷」看前 15 分钟（init / add / commit / push），看 5 分钟就动手敲
2. GitHub 注册 + New repository（名字 engine-phm-study，选 Public，**三个勾选框都不勾**）
3. 执行：

       git config --global user.name "你的名字"
       git config --global user.email "你的邮箱@qq.com"
       git config --global core.quotepath false

       git init
       git branch -M main
       git status          # 先看
       git add .
       git status          # 关键：确认没有 .venv/ 和 data/raw/
       git commit -m "chore: 初始化项目骨架与环境配置"
       git remote add origin https://github.com/你的用户名/engine-phm-study.git
       git push -u origin main

4. 刷新 GitHub 页面，能看到 README 和目录结构即成功
