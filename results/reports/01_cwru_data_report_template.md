## 7. 局限与下一步

**本报告的局限**
- 只用了单一工况（0 HP、单一转速），未验证跨工况泛化性
- 只用了 DE 一个通道，未融合 FE / BA 通道
- 只做了单段信号的静态特征，没有做滑窗时序分析
- 只用了时域 + 简单频域特征，**没有包络谱**，无法定位故障特征频率

**下一步计划**
1. 实现 `src/features.py` 中的 `bandpass_filter()` 与 `envelope_spectrum()`
2. 计算 CWRU 的理论故障特征频率（BPFO / BPFI / BSF），与包络谱峰值对照
3. 加入小波/时频特征，构建完整特征库
4. 扩展到多工况（1/2/3 HP），尝试跨工况迁移
